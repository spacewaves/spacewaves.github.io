# Space Waves — Free Neon Wave Arcade Game

Space Waves is an original HTML5/JavaScript browser arcade game in the wave-obstacle genre. It uses original game code, neon visuals, and a hand-designed obstacle course. It is not the source code or an official version of Space Waves.

## Features
- Neon visuals and a futuristic grid
- Keyboard, mouse, and touch controls
- Obstacle collision, particle effects, and restart flow
- Responsive game canvas
- On-page SEO metadata, Open Graph/Twitter tags, and VideoGame structured data
- English instructions and supporting page content

## Deploy to GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html` and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select branch `main` and folder `/(root)`, then click **Save**.
5. After deployment, the site URL will typically look like `https://USERNAME.github.io/REPOSITORY/`.

## Embed with an iframe
Replace the URL with your published GitHub Pages URL:

```html
<iframe src="https://USERNAME.github.io/REPOSITORY/" width="100%" height="650" style="border:0;display:block" allowfullscreen title="Space Waves — Free Neon Wave Arcade Game"></iframe>
```

## Controls
- Hold Space, W, Up Arrow, mouse button, or touch: rise
- Release: descend
- Escape: pause

## SEO notes
The canonical URL and social preview URLs are set to `https://spacewaves.github.io/`. The Open Graph image URL is a placeholder; add a real `og-image.png` (ideally 1200 × 630) to the site root or update the metadata to an image that exists.

## Publishing and rights
This is an independent game inspired by the general wave-arcade genre. It does not include assets from Space Waves. Continue using original names, logos, graphics, and audio when publishing.
