# Neon Rift — Wave Arcade

Một game arcade HTML5/JavaScript nguyên bản lấy cảm hứng từ thể loại wave obstacle runner. Tên, đồ họa, màn chơi, hiệu ứng và mã nguồn trong dự án này được tạo mới; đây không phải bản sao hay mã nguồn của Space Waves.

## Chạy thử
Mở `index.html` trong trình duyệt hoặc chạy bằng một static web server.

## Triển khai GitHub Pages
1. Tạo repository mới trên GitHub.
2. Upload `index.html` và `README.md` vào thư mục gốc.
3. Vào **Settings → Pages**.
4. Chọn **Deploy from a branch**, branch `main`, folder `/(root)`, nhấn **Save**.
5. Đợi GitHub Pages triển khai xong. URL thường có dạng `https://USERNAME.github.io/REPOSITORY/`.

## Nhúng bằng iframe
Thay URL bằng URL Pages thực tế của bạn:

```html
<iframe
  src="https://USERNAME.github.io/REPOSITORY/"
  width="100%"
  height="650"
  style="border:0;display:block"
  allowfullscreen
  title="Neon Rift — Wave Arcade">
</iframe>
```

## Điều khiển
- Giữ Space, W, mũi tên lên, chuột hoặc chạm màn hình: bay lên.
- Thả ra: hạ xuống.
- Escape: tạm dừng.

## Lưu ý
Dự án này là bản game nguyên bản cùng thể loại, không bao gồm tài sản từ Space Waves. Nếu phát hành công khai hoặc thương mại, hãy tiếp tục dùng tên, logo, âm thanh và hình ảnh của riêng bạn.
